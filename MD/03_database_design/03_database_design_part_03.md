# ==========================================================
# Daily Activity Module
# ==========================================================

يمثل هذا الجزء جميع البيانات التشغيلية (Operational Data) التي يتم إنشاؤها يومياً بواسطة الاستشاريين.

وتعتبر هذه الجداول المصدر الرئيسي لجميع التقارير والإحصائيات داخل النظام.

# ==========================================================
# دورة تنفيذ المهمة
# ==========================================================

عندما يختار الاستشاري موقعاً، يعمل النظام بالترتيب التالي:

1.

فتح الزيارة.

↓

2.

جلب جميع المهام الخاصة بالموقع.

↓

3.

عرض عناصر الإدخال الخاصة بكل مهمة.

↓

4.

يقوم الاستشاري بإدخال البيانات.

↓

5.

إنشاء Task Response لكل مهمة تم تنفيذها.

↓

6.

إنشاء Task Response Values لكل عنصر إدخال.

↓

7.

رفع الصور (إن وجدت).

↓

8.

إنشاء Task Attachments.

↓

9.

حفظ الزيارة.

# ==========================================================
# ملاحظات تصميمية
# ==========================================================

## القرار الأول

تم فصل استجابة المهمة عن قيم عناصر الإدخال.

وذلك لأن المهمة الواحدة قد تحتوي على عدد غير محدود من عناصر الإدخال.

---

## القرار الثاني

تم فصل المرفقات عن قيم الإدخال.

حتى يمكن دعم أنواع ملفات متعددة مستقبلاً دون تعديل التصميم.

---

## القرار الثالث

لا يتم تخزين الصور داخل جدول الإجابات.

بل يتم تخزينها داخل جدول مستقل.

---

## القرار الرابع

جميع البيانات التشغيلية تعتبر سجلات تاريخية.

ولا يتم تعديلها بعد حفظها إلا في حالات استثنائية يحددها النظام.

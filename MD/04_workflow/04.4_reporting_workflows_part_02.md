# مقدمة

يكمل هذا الملف تصميم نظام التقارير والتحليلات داخل النظام.

يركز هذا الجزء على التقارير المتقدمة التي تساعد الإدارة على تحليل:

- نشاط المواقع.
- الحضور والالتزام.
- أداء المهام.
- سلوك الاستشاريين.
- البيانات التاريخية.

كما يغطي هذا الجزء الوظائف المساندة للتقارير:

- البحث.
- الفلترة.
- الترتيب.
- التصدير.
- الصلاحيات.
- التقارير المجدولة.

# ==========================================================
# Engine 05 — Site Activity Reports Engine
# ==========================================================

## الهدف

تحليل نشاط المواقع الميدانية ومعرفة مستوى المتابعة لكل موقع.

يعتمد التقرير على:

- Site Visits.
- Consultant.
- Date Range.
- Task Responses.

---

# Workflow 01 — Generate Site Activity Report

## Trigger

طلب تقرير نشاط المواقع.

---

## Filters

يدعم التقرير:

```text
Date Range

Site

Consultant

Task Type

Visit Status
```

---

## System Flow

```text
استقبال الفلاتر

↓

قراءة Site Visits

↓

ربط الزيارات بالمواقع

↓

ربط الزيارات بالاستشاريين

↓

تجميع النتائج

↓

عرض التقرير
```

---

# Report Metrics

يعرض:

```text
Site Name

Number Of Visits

Number Of Consultants

Completed Tasks

Additional Tasks

Last Visit Date
```

---

# Example Output

| Site | Visits | Tasks | Consultants |
|---|---:|---:|---:|
| Project A | 45 | 320 | 5 |
| Project B | 30 | 210 | 3 |
| Project C | 18 | 120 | 2 |

# مقدمة

يوثق هذا الملف جميع العمليات التي ينفذها قسم الموارد البشرية (HR).

جميع العمليات الموجودة هنا مسؤولة عن إعداد النظام وإدارة بياناته الأساسية، ولا تتضمن تنفيذ الأعمال الميدانية الخاصة بالاستشاريين.

---

# ==========================================================
# Workflow 01 — Create Site
# إنشاء موقع جديد
# ==========================================================

## Objective

إضافة موقع جديد ليصبح متاحاً للاستشاريين عند تسجيل الزيارات.

---

## Preconditions

- المستخدم يمتلك صلاحية HR.
- الموقع غير موجود مسبقاً.

---

## Workflow Steps

```text
فتح صفحة المواقع

↓

اختيار "إضافة موقع"

↓

إدخال بيانات الموقع

↓

حفظ
```

---

## System Actions

يقوم النظام بـ:

- التحقق من صحة البيانات.
- إنشاء سجل جديد داخل جدول Sites.
- جعل الموقع متاحاً في قائمة المواقع.

---

## Outcome

أصبح الموقع جاهزاً للاستخدام.

---

## Related Business Rules

BR-020

BR-021

BR-022

---

## Exceptions

- اسم موقع مكرر.
- كود موقع مكرر.

---

# ==========================================================
# Workflow 02 — Update Site
# تعديل موقع
# ==========================================================

## Objective

تعديل بيانات موقع موجود.

---

## Preconditions

- الموقع موجود.
- المستخدم يمتلك صلاحية HR.

---

## Workflow Steps

```text
اختيار الموقع

↓

تعديل البيانات

↓

حفظ
```

---

## System Actions

- تحديث بيانات الموقع.
- الاحتفاظ بجميع الزيارات التاريخية.

---

## Outcome

يتم تحديث بيانات الموقع دون التأثير على السجلات السابقة.

---

# ==========================================================
# Workflow 03 — Disable Site
# تعطيل موقع
# ==========================================================

## Objective

إيقاف استخدام الموقع دون حذفه.

---

## Workflow Steps

```text
اختيار الموقع

↓

تعطيل
```

---

## System Actions

- تغيير حالة الموقع إلى Inactive.
- إخفاؤه من قائمة المواقع الجديدة.
- عدم التأثير على البيانات التاريخية.

# ==========================================================
# Workflow 11 — Update Consultant
# تعديل بيانات الاستشاري
# ==========================================================

يشمل:

- تعديل البيانات الشخصية.
- تغيير جدول العمل.
- تغيير حالة الحساب.

ولا يؤثر على السجل التاريخي.

---

# ==========================================================
# Workflow 12 — Disable Consultant
# إيقاف استشاري
# ==========================================================

عند الإيقاف:

- يمنع تسجيل الدخول.
- تبقى جميع البيانات محفوظة.
- لا يتم حذف أي سجل.

↓

---

# ==========================================================
# Workflow 14 — Update Leave
# تعديل الإجازة
# ==========================================================

يسمح بتعديل:

- البداية.
- النهاية.
- السبب.

ويعاد احتساب الأيام المتأثرة.

---

# ==========================================================
# Workflow 15 — Delete Leave
# حذف الإجازة
# ==========================================================

بعد الحذف،

يقوم النظام بإعادة احتساب الحضور والغياب لتلك الفترة.

---

# ==========================================================
# Workflow 16 — Create Official Holiday
# إضافة عطلة رسمية
# ==========================================================

يقوم HR بتحديد:

- التاريخ.
- اسم العطلة.

بعد الحفظ،

يتم استثناء اليوم لجميع الاستشاريين.

---

# ==========================================================
# Workflow 17 — Update Official Holiday
# تعديل عطلة
# ==========================================================

يسمح بتعديل بيانات العطلة.

ثم يعيد النظام احتساب الأيام المتأثرة.

---

# ==========================================================
# Workflow 18 — Delete Official Holiday
# حذف عطلة
# ==========================================================

بعد الحذف،

يعاد احتساب الحضور والغياب لذلك اليوم.

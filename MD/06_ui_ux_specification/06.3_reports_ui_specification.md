# Purpose

يوثق هذا الملف جميع واجهات مستخدم التقارير (Reports UI) داخل النظام، ويصف بنية كل شاشة تقرير، والغرض منها، والمكونات الرئيسية (Filters, Charts, Data Grids)، وآلية التنقل، بالإضافة إلى الإجراءات المتاحة مثل التصدير (Export) والتعمق في التفاصيل (Drill Down).

تم تقسيم هذا الملف ليوثق التقارير الخاصة بمسؤولي النظام (HR Reports) والتقارير الخاصة بالاستشاري (Consultant Reports).

---

# Introduction

تعتبر واجهات التقارير الوسيلة الأساسية لقراءة بيانات الأداء المجمعة (Aggregated Data). 

تعتمد جميع واجهات التقارير على المبادئ التالية:

- المحافظة على حالة الفلاتر (Filters) أثناء التنقل.
- تقديم نظرة عامة بصرية (Charts) تليها تفاصيل جدولية (Data Grid).
- الاعتماد على طبقة التجميع (Layered Aggregation) الموضحة في Revision 1.1 لضمان سرعة التحميل.
- تمكين المستخدم من التعمق في البيانات (Drill Down) دون مغادرة الصفحة باستخدام الـ Drawers.
- الالتزام بجميع قواعد التصميم الموجودة في:

06.0_ui_design_rules.md

# Module 01 — HR Reports

## الهدف

توفير شاشات تقارير شاملة لمسؤولي النظام (HR) تتيح لهم مراقبة الأداء العام، تقييم الاستشاريين، وتحليل زيارات المواقع لفترات زمنية مخصصة.

يتكون هذا القسم من:

- R1-P01 — Reports Dashboard
- R1-P02 — Consultants Performance Report
- R1-P03 — Sites Visits Report
- R1-R01 — Report Drill Down Details

---

# R1-P01 — Reports Dashboard

## Screen Type

Full Page

---

## Complexity

Low

---

## Purpose

شاشة مركزية (Hub) تتيح لمسؤول الـ HR الوصول السريع إلى جميع التقارير المتاحة في النظام.

---

## Entry Points

- Side Navigation (Reports)

---

## Layout

تتكون الصفحة من بطاقات (Cards) كبيرة، تمثل كل بطاقة نوعاً من التقارير:

### Card 1: Consultants Performance

- **Title:** أداء الاستشاريين
- **Description:** عرض تقارير الإنجاز اليومي والشهري للاستشاريين.
- **Action:** زر "Open Report"

### Card 2: Sites Visits

- **Title:** زيارات المواقع
- **Description:** تقرير تحليلي لعدد الزيارات والمهام المنفذة لكل موقع.
- **Action:** زر "Open Report"

---

# R1-P02 — Consultants Performance Report

## Screen Type

Full Page

---

## Complexity

High

---

## Purpose

التقرير الرئيسي لتقييم أداء الاستشاريين بناءً على نسبة الإنجاز والمهام المنفذة (اليومية والإضافية) خلال فترة محددة.

---

## Interaction Flow


Reports Dashboard

↓

Consultants Performance Report

↓

تحديد الفلاتر (تاريخ، استشاري)

↓

تحديث الرسوم البيانية والجدول

↓

الضغط على صف للتعمق (Drill Down)

↓

فتح Drawer التفاصيل


## Layout

تتكون الصفحة من:

- Report Header & Export Actions
- Global Filters
- Visual Charts
- Data Grid

---

## Section 01 — Global Filters

- Date Range: (From Date - To Date) افتراضياً يعرض الشهر الحالي.

- Consultant: Dropdown لاختيار استشاري معين أو تركها "الكل".

- Employment Status: Active / Inactive.

---

## Section 02 — Visual Charts

### Top / Bottom Performers (Bar Chart)

يعرض أعلى 5 استشاريين وأقل 5 استشاريين من حيث نسبة الإنجاز خلال الفترة المحددة.

### Organization Trend (Line Chart)

يعرض متوسط أداء الشركة ككل عبر أيام أو أسابيع الفترة المحددة.

---

## Section 03 — Data Grid (الجدول)

### Columns

- Employee Number

- Full Name

- Working Days (أيام العمل الفعلية)

- Required Daily Tasks (المهام الإلزامية المطلوبة)

- Completed Daily Tasks (المهام المنجزة)

- Average Completion % (نسبة الإنجاز)

- Additional Tasks (المهام حسب الحاجة)

### Row Actions

- View Details: يفتح R1-R01 (Drill Down).

### Bulk Actions

- Export to Excel

- Export to PDF

Full Page

## Purpose

---

## Entry Points

- Consultant Dashboard

---

## Layout

تتكون الصفحة من:

- Filters

- Personal KPIs

- Trend Chart

---

## Section 01 — Filters

- Date Range: (From Date - To Date) افتراضياً يعرض الشهر الحالي.

## Section 02 — Personal KPIs (Summary Cards)

تعرض:

- Total Working Days (ضمن الفترة)

- Average Completion %

- Total Additional Tasks

---

## Section 03 — Trend Chart

### Line Chart

يوضح التغير في نسبة الإنجاز اليومية (Daily Completion %) على مدار أيام الفترة المحددة، مما يتيح للاستشاري رؤية أيام نشاطه وأيام انخفاض الأداء.

---

## Section 04 — Daily Records Grid

يعرض تفاصيل الأيام المندرجة تحت الفترة المحددة (سجلات يومية).

### Columns

- Date

- Sites Visited (عدد المواقع)

- Daily Tasks %

- Additional Tasks Count

- Status (حاضر / غائب / إجازة / عطلة)

### Row Actions

- View Visit Summary: لفتح نافذة منبثقة (Dialog) تعرض ملخص ما تم تعبئته في ذلك اليوم كمرجع فقط (Read-Only).

### Export Action

- Export to PDF: في أعلى الصفحة لطباعة التقرير الشخصي وتسليمه إن لزم الأمر.

# ==========================================================
# Edge Cases Handling in Reports UI
# ==========================================================

## Case 01 — Empty Data Range

الحالة: اختيار نطاق زمني لا يحتوي على أي بيانات أو زيارات.

سلوك الواجهة: إخفاء الجداول والرسوم البيانية، وعرض مكون (Empty State) يحمل أيقونة توضيحية ورسالة "لا توجد بيانات متاحة لهذه الفترة".


---

## Case 02 — Heavy Data Processing

الحالة: قيام مسؤول الـ HR بطلب تقرير (Consultants Performance) لسنة كاملة لجميع الموظفين.

سلوك الواجهة: عرض Skeleton Loader أو Spinner واضح يغطي منطقة الجدول والرسوم، مع تعطيل زر (Apply) مؤقتاً لتجنب إرسال طلبات متكررة للسيرفر، وإظهار رسالة "جاري تجميع التقرير...".


---

## Case 03 — Exporting Large Tables

الحالة: النقر على Export لجدول يحتوي على آلاف الصفوف.

سلوك الواجهة: إظهار Notification (Toast) يوضح أن "عملية التصدير قيد المعالجة في الخلفية وسيتم التحميل فور الانتهاء".

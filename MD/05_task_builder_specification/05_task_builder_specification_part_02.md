# مقدمة

يمثل هذا الجزء المحرك الأساسي لمنشئ المهام الديناميكي:

```text
Dynamic Fields Engine
```

الفكرة الأساسية هي أن المهمة داخل النظام لا تحتوي على شكل إدخال ثابت.

بل يقوم HR بتحديد:

- ما هي البيانات المطلوبة؟
- كيف يتم إدخالها؟
- هل هي إجبارية؟
- هل تظهر حسب شرط معين؟
- كيف يتم التحقق منها؟

ثم يقوم النظام تلقائياً بإنشاء النموذج المناسب للاستشاري.

---

# ==========================================================
# Engine 01 — Dynamic Fields Concept
# ==========================================================

## الهدف

تحويل المهمة من مجرد اختيار ثابت إلى نموذج ديناميكي قابل للتوسع.

---

## الشكل التقليدي

مثال:

```text
Task:

استلام الأرضيات


Fields ثابتة داخل البرمجة:

- Checkbox
- Comment
```

المشكلة:

أي تغيير يحتاج تعديل برمجي.

---

## الشكل المقترح

```text
Task Definition

↓

Field Definitions

↓

Dynamic Form

↓

Consultant Response
```

---

# مثال

يقوم HR بإنشاء مهمة:

```text
استلام الخرسانة
```

ويضيف الحقول:

```text
Checkbox:
تم الاستلام؟


Number:
رقم الصبة


Date:
تاريخ الصب


Textarea:
الملاحظات


Image:
صور الموقع
```

النظام يقوم بإنشاء النموذج تلقائياً.

# ==========================================================
# Engine 05 — Conditional Fields
# ==========================================================

## الهدف

إظهار حقول بناءً على إجابات سابقة.

---

# Concept

ليس كل الحقول تظهر دائماً.

---

# Example 01

المهمة:

```text
فحص جودة
```

الحقل الأول:

```text
هل يوجد ملاحظات؟
```

الخيارات:

```text
نعم

لا
```

---

إذا اختار:

```text
نعم
```

يظهر:

```text
حقل الملاحظات
```

---

إذا اختار:

```text
لا
```

يبقى مخفياً.

---

# Conditional Rule Structure

```text
IF

Field A = Value

THEN

Show Field B
```
